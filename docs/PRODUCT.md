# PREMORTEM HUB — краткое описание продукта

## Что это
PREMORTEM HUB — это **инструмент принятия решения по идее/проекту**, который помогает быстро увидеть экономику, туман и иллюзии, чтобы понять: двигаться дальше или сначала проверить гипотезы.

## Кому нужно
- **Предпринимателю / самозанятому**, который запускает новую идею.
- **Человеку с несколькими идеями**, чтобы быстро выбрать одну.
- **Руководителю / операционке**, чтобы оценить риски и узкие места.

## Зачем
- Получить **чёткий вердикт** (запускать / доработать / пауза / закрыть).
- Понять **экономику** в трёх сценариях.
- Увидеть **где туман** (FogI) и **где иллюзии** (IllI).
- Сформировать **план действий** на ближайшие 1–2 недели.

## Как пользоваться
1. Создать проект и пройти **Premortem Lite** (7 шагов).
2. Открыть **Отчёт** и посмотреть резюме + «что чинить в первую очередь».
3. Если нужно глубже — подключить вкладки **Segments / Operations / Portfolio**.
4. Сохранить и при необходимости сделать **экспорт JSON**.

> Маршрут по умолчанию: **Premortem Lite → Отчёт**. Остальные модули — углубление.

## Пример использования
> «Есть идея сервиса по подбору мастеров. В Premortem Lite описал клиента/проблему/решение, ввёл диапазоны цены и спроса. Отчёт показал отрицательную прибыль в базовом сценарии и высокий FogI. Решение: сначала проверить спрос и пересчитать экономику, не запускать разработку сразу.»
