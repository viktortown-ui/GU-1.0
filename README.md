# PREMORTEM HUB - Инструкция по запуску

## F) Инструкция запуска

### Минимальные требования
- **Браузер**: Любой современный браузер (Chrome, Firefox, Safari, Edge)
- **JavaScript**: Включен (по умолчанию в современных браузерах)
- **Интернет**: Только для первой загрузки (работает offline после загрузки)

### Способы запуска

#### Способ 1: Открыть напрямую в браузере (самый простой)
1. Скачайте все файлы проекта в одну папку
2. Откройте файл `index.html` двойным кликом или перетащите его в окно браузера
3. Приложение запустится автоматически

#### Способ 2: Через локальный веб-сервер (рекомендуется для разработки)
```bash
# Перейдите в папку проекта
cd /путь/к/папке/premortem-hub

# Запустите сервер (одна из команд)
python -m http.server 8000
# или
python3 -m http.server 8000
# или
npx serve .
```
Затем откройте браузер и перейдите по адресу: `http://localhost:8000`

#### Способ 3: Развернуть на хостинге
1. Загрузите все файлы на любой статический хостинг (GitHub Pages, Netlify, Vercel)
2. Убедитесь, что `index.html` находится в корне
3. Приложение будет работать как обычный сайт

### Структура файлов
```
premortem-hub/
├── index.html              # Главная страница со списком проектов
├── app.html               # Рабочая область с модулями
├── main.js                # Точка входа и менеджер проектов
├── docs/
│   └── PRODUCT.md         # Цель продукта и сценарий использования
├── modules/
│   ├── PremortemLite.js   # Модуль Premortem Lite (7 шагов)
│   ├── Segments.js        # Модуль Сегменты рынка
│   ├── Operations.js      # Модуль Операционная устойчивость
│   └── Portfolio.js       # Модуль Портфель идей
├── utils/
│   ├── NumberUtils.js     # Безопасные числовые утилиты
│   ├── Storage.js         # Работа с localStorage
│   ├── ExportImport.js    # Экспорт/импорт JSON
│   └── Calculators.js     # Формулы расчетов
└── README.md              # Этот файл
```

### Быстрый старт

1. **Создание проекта**: Откройте приложение, нажмите "Создать первый проект"
2. **Заполнение данных**: Перейдите через все 7 шагов Premortem Lite
3. **Анализ сегментов**: Добавьте сегменты рынка в модуле "Сегменты"
4. **Операционная устойчивость**: Оцените ресурсы и загрузку
5. **Портфель**: Добавьте идеи и запустите симуляцию

### Резервное копирование

Все данные хранятся локально в браузере. Для резервного копирования:
1. На главной странице нажмите "Экспорт всех"
2. Сохраните JSON файл
3. Для восстановления нажмите "Импорт" и выберите файл

### Экспорт/Импорт проектов
- **Экспорт одного проекта**: В рабочей области нажмите "Экспорт"
- **Экспорт всех проектов**: На главной странице "Экспорт всех"
- **Импорт**: Поддерживает как отдельные проекты, так и полные бэкапы

### Документы
- **PRODUCT.md** — кратко: цель продукта, для кого он, как пользоваться. См. `docs/PRODUCT.md`.

### Работа offline
Приложение полностью работает без интернета после первой загрузки. Данные сохраняются между сессиями в localStorage браузера.

### Совместимость
- ✅ Chrome 80+
- ✅ Firefox 75+
- ✅ Safari 13+
- ✅ Edge 80+
- ❌ Internet Explorer (не поддерживается)

### Поддержка
Если возникли проблемы:
1. Очистите кэш браузера (Ctrl+Shift+Delete)
2. Проверьте, что JavaScript включен
3. Откройте консоль разработчика (F12) для просмотра ошибок

## E) Полный код

Все файлы проекта находятся в папке `/mnt/okcomputer/output/`. Приложение написано на чистом JavaScript без внешних зависимостей (кроме Tailwind CSS через CDN для стилизации).

### Ключевые особенности реализации:
- **Модульная архитектура**: Каждый модуль = отдельный класс
- **Offline-first**: localStorage для хранения данных
- **Event-driven**: Связь между компонентами через события
- **Auto-save**: Автоматическое сохранение при изменениях
- **Responsive UI**: Адаптивный дизайн для всех устройств
